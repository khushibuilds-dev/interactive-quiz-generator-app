# 🚀 Quiz Generator App

This is a simple web-based Quiz Generator application. I built this project to learn and practice fundamental frontend web development concepts under my mentor's guidance.

## 🧠 What I Learned & Practiced (DOM Manipulation)
The main goal of this project was to learn how JavaScript interacts with HTML. Through this project, I practiced:
- **DOM Manipulation:** Learning how to select, change, and update HTML elements using JavaScript.
- **Event Listeners:** Handling user clicks when they select answers or move to the next question.
- **Conditional Logic:** Checking if the user's answer is correct or incorrect and calculating the score.
- **Basic Functions:** Writing clean JavaScript functions to handle the quiz flow.

## 🛠️ Technologies Used
- **HTML5:** For creating the structure of the quiz.
- **CSS3:** For changing the colors, design, and layout.
- **JavaScript (ES6):** For adding the logic and making the quiz work.

## 📂 How to Run the Project
1. Download or clone this repository.
2. Open the folder on your computer.
3. Double-click the `index.html` file to run the quiz in your browser.
